---
description: List the NetSuite saved searches available to you (optionally run one)
argument-hint: [filter text]
---

Use the connected NetSuite connector's **list saved searches** tool to show the
saved searches available, as a table (id · name · type). If **$ARGUMENTS** is
given, filter the list to names containing that text.

If the user then names one, offer to run it with the connector's **run saved
search** tool and present the result as a table.
