# Local sanitized NetSuite stills

Place the exact sanitized NetSuite frames used by the detailed client guide in
this directory. The directory is ignored by Git because the source recordings
can contain client names and one-time credentials.

Required filenames:

- `ns-consumer.png`
- `ns-token-form-43.png`
- `ns-token-confirm.png`

The Remotion composition adds opaque privacy covers, but the local asset must
also be reviewed before rendering. Verify that no account ID, person name,
email address, URL, Consumer Key, Consumer Secret, Token ID, or Token Secret is
visible in an uncovered region.
