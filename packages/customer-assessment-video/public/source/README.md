# Local source recordings

Place sanitized recordings here. This directory is ignored by Git.

Required filenames:

- `netsuite-token-safe.mp4`

The NSPB walkthrough uses exact frozen frames instead of accelerated source
video so every export step remains readable and its focus box cannot drift.

Before copying a recording, remove or cover account IDs, employee names, email
addresses, URLs, tokens, secrets, and any client-specific values that are not
necessary to explain the workflow.
