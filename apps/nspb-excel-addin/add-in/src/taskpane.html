🚀 FIRST-TIME SETUP

Three things to fill in once, then everything works.

Settings — required fields

  • Host — Oracle EPM Cloud URL (e.g. https://xxx.epm.oraclecloud.com)
  • Username / Password — your NSPB login (Basic Auth, stateless)
  • Application — Planning application name (e.g. NetSuite)
  • Gemini API key — from Google AI Studio (starts with AIza…)

Click Save, then Test connections — validates BOTH NSPB and Gemini in a single click.

Detect everything (run once per tenant)

Settings → 🔍 Detect everything. Probes all Planning + Data Management endpoints, builds the catalog of cubes / dimensions / forms / rules / variables / jobs / integrations / apps. Writes NSPB_Discovery sheet. Takes 30–60 seconds. Re-run if you switch tenants.

Import KB (LCM-parsed)

Settings → Import KB → pick the tenant-kb.json file. This is the LCM-export-derived knowledge base built for your tenant (forms with descriptions, rules with descriptions, navigation flows, dashboards). Without this, the AI knows the tenant only via live API; with it, it has rich context for every form / rule.

Client snapshots — switch tenants fast

Save the whole tenant state (settings + KB + caches) as one JSON; restore later. Useful when working across multiple clients.

  • Settings → 👤 Export client → type a name → downloads X_2026-04-30.nspb-client.json
  • Settings → 👤 Import client → file picker → reload pane
  • Settings → 🗑️ Clear everything → wipes all caches + settings (use before sharing for support)

⚡ QUICK START — type ? or a verb

The fastest way to discover everything: type ? in the chat input. The master tree opens showing every command, grouped by verb. Keep typing to filter, ↑↓ to navigate, Enter to fill, Esc to close.

Or type the verb directly — the palette drills into that category automatically:

🧠 AI features (the daily ones)

  • analyze — insights + KPIs + HTML report on the active sheet (variance, trends, top movers). Examples: analyze this sheet, analyze top variance drivers.
  • close ⭐ — formal multi-page month-end close pack (cover · exec summary · P&L · BS · CF · KPIs · variance commentary · appendix). 5 recipes: quick / standard / full / board / audit. Examples: close standard, close board pack, close with sections: cover, pnl_statement.
  • explain ⭐ — AI tutor grounded in your tenant. Reads rule bodies (Groovy/CalcScript) from the LCM-parsed KB. Examples: explain rule (live picker), explain form (live picker), explain account Revenue, why is Total Selling Expenses zero.
  • navigate ⭐ — Smart View ad-hoc navigation: cube-aware zoom / pivot / keep / explain-cell. Examples: navigate explain this cell, navigate show bottom level, zoom in on Revenue.
  • cell history ⭐ — change history for the selected cell: who changed it, when, and old→new value (via SmartView's audit trail). Select a data cell in an open form/grid, then ask. Examples: who changed this cell, cell history, quién modificó esta celda. Requires Data Audit enabled in the app.

📋 NSPB operations (browse / open / run)

  • show — list forms, rules, variables, jobs, integrations, navigation flow. Examples: show forms, show vars, show rules.
  • open — load a form into Excel (with metadata + rules + chips for next moves). Examples: open form Income Statement, open dashboard.
  • run — execute a business rule, job, or DM integration. Examples: run rule (picker), run integration.

🎨 Sheet transformations

  • adapt — map a free-form client sheet to a NSPB form (preview before applying).
  • format — apply variance-report styling, clean zero rows, freeze panes.
  • transform — pivot a sheet into Smart View ad-hoc shape.

📤 Reports (output)

Every report bubble has three chips: 📄 HTML (download) · 🖨 PDF (server-rendered, exact same design) · 👁 Preview (iframe inline in the chat, sandboxed). Reports use an editorial design system (Sarabun typography, navy/green/gold palette).

🆚 WHEN TO USE WHAT

  • analyze — ad-hoc insight on whatever's in front of you (quick, ~5 sec).
  • close — formal multi-page deliverable for stakeholders (~25-50 sec).
  • explain — when you don't understand WHAT a rule / form / account is or does.
  • navigate — when you're in a grid and need to drill / pivot / understand the dim context.
  • open + run — direct NSPB operations.
  • format — visual polish on a sheet you already have.
  • adapt + transform — bring outside data into NSPB structure.

⚙️ TENANT ADMIN (deeper operations)

For administrative work, type one of these verbs or browse them via ?:

  • set — set ONE substitution variable (live REST).
  • update — bulk variable editor, dimension members.
  • change — rename a member alias.
  • import — submit a dimension or data import.
  • export — pull dimension, cube data, security, audit log.
  • delete — remove a file from inbox / outbox.

🛠️ TROUBLESHOOTING

Common fixes:

  • Debug mode — Settings → toggle on to see tool calls + timings in the chat.
  • Stuck or strange behavior — close Excel completely, run Customer_Installer/Uninstall NSPB.bat then Install NSPB.bat. Clears Wef cache + registry.
  • "Couldn't decide which tool" — re-phrase using a verb (e.g. start with analyze, explain, close) or pick from the palette.
  • "No active sheet" — click into the sheet you want before sending the message.
  • PDF chip says "unavailable" — fall back to the HTML download, then Print → Save as PDF.

🦆 DUCKDB ENGINE — INTRO

DuckDB-WASM is a columnar OLAP database (~5 MB) running entirely in this task pane. Data never leaves your machine. Use it to audit a big SmartView pivot, run repeated ask: questions without burning credentials/network, and do variance / coverage / trend analysis across a year of data without rebuilding grids.

⚡ EVERYTHING IS IN /data

Type /data in the chat input. The palette has all DuckDB ops:

  • Load & manage tables — load smartview as today, tables, drop table, sql: ….
  • Missing Forecast checks 🔴🟠 — Load $ / Units, FY25 / FY24, full year / quarter slices.
  • Missing Budget checks 🟡🟢 — Load $ / Units, current and upcoming plan years.
  • Lost customer checks 🔵 — auto-detects current period, defaults to last 3 silent months. Variants: last=2, only=forecast, only=budget, tracker=Unit.

🤖 AI questions: /analyze for free-form ask:

Once a table is loaded, every Top-N / variance / trend / pricing / coverage query lives in /analyze. They use the ask: prefix → Gemini writes the SQL → DuckDB runs it locally → result back in chat. Cost: ~$0.0002 per question.

  • Always say scenario (actual / budget / forecast), year (FY25), tracker (load or unit), and periods (TP1-TP9). The more explicit, the more reliable the generated SQL.
  • Use sql: … as a power-user escape hatch when you want to write the query yourself.

🛠️ HOW IT WORKS UNDER THE HOOD

  • Load smartview — flattens the active SmartView pivot (POV + Tracker × Scenario × Years × Period column headers + row dim headers + data) into a long-format record per cell. Schema is auto-detected.
  • Deterministic checks — pure SQL anti-joins / CTE pipelines on all row dims (no AI). ~100-500 ms on 600k+ rows. Each check picks a unique color hashed from the full command, so multi-pass overlays don't overwrite.
  • ask: queries — schema-only prompt to Gemini (~200 tokens). Low-cardinality columns sent in full; high-cardinality cols sent as names only with LIKE matching. Rows never travel.
  • Painting — missing cells grouped into contiguous ranges, flushed in one ctx.sync(). ~1-2s for thousands of cells.

💰 COSTS

  • DuckDB load & /data checks — $0. Local only.
  • ask: question — ~$0.0002 (~5,000 questions per dollar).
  • Active-grid analyze — ~$0.001 (still very cheap).
  • Rule of thumb: a typical day of work costs < $0.05 in Gemini tokens.

🩹 TROUBLESHOOTING

  • "No tables loaded" — run load smartview as today while parked on the SmartView sheet.
  • "Parsed 0 records" — the active sheet doesn't look like a SmartView pivot. Verify Tracker / Scenario / Years / Period column headers above the row dim header.
  • Wrong sheet painted — fixed: the add-in remembers the sheet you loaded from. If it slips, re-run load smartview as today.
  • Gemini gets it wrong — be more explicit with scenario/year/tracker/period. Or switch to sql: ….
  • Gemini quota exceeded — change API key in Settings; free tier resets daily.

Discover your environment

Click 🔍 Detect everything (recommended once per environment). It probes all Planning endpoints and writes an NSPB_Discovery sheet showing what was found. This takes 30–60 seconds and must complete before ad-hoc queries work reliably.

You can also run individual discoveries: Dims · Rules · Forms · Vars · Jobs · Integ · Apps.

Build a data grid

Type a finance question in plain English. The add-in calls the right NSPB endpoint and writes the result to a new Excel sheet.

  • revenue by month FY25 forecast
  • opex by department Q1 actual
  • headcount by subsidiary FY25 budget
  • P&L summary YearTotal actual vs budget

Navigate a grid

Once a grid is on screen, you can keep drilling without rebuilding from scratch:

Tips

  • Glossary — in Settings, describe your tenant's conventions in plain text (e.g. "revenue is under ACCT_4000, periods are Jan–Dec"). Gemini uses this as extra context.
  • Debug mode — toggle in Settings to see the exact tool calls and timings in chat.
  • Re-run Detect if you switch to a different Planning application.
  • Session-auth endpoints (navigation tree, period mappings, DM file browser) require the NSPB web UI session and are not available via the add-in. They show an explanatory sheet instead of crashing.
