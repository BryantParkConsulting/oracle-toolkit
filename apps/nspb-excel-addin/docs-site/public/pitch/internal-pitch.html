05 · Architecture
How It Works

Built to scale, with no infrastructure overhead.

STEP 01

User types a question in Excel.

Natural-language prompt, in the same workbook the team already uses.

STEP 02

AI interprets & selects an action.

Gemini 2.5 maps the prompt to the right NSPB operation — query, form, rule, or job.

STEP 03

Action runs directly in NSPB.

The assistant calls the NSPB API on the user's behalf — no clicks, no menus.

STEP 04

Result returns to Excel instantly.

Numbers, confirmation messages, or refreshed forecasts — back in the workbook.

No servers of our own — Cloudflare Workers
Configurable per client in minutes — automated parser
Extensible to NSAW, NSAR, and any product with an API
Centrally hosted — every client always on the latest version

Maintenance & Team Capacity

What it takes to keep this running.

The product has a built-in feedback loop. Each week we triage, fix, and deploy — for every client at once.

Dedicated time required · per phase
Launch · months 1–2
~50% of one engineer

Hardening the parser, onboarding the first 3–5 clients, closing critical bugs from real usage.

Steady · months 3–6
~25% of one engineer

Weekly bug triage + deploy. New features driven by client feedback. KB updates for new NSPB releases.

Scale · 6+ months
~15% + new feature spikes

Maintenance is light. Larger spikes when extending to NSAW / NSAR — scoped as separate initiatives.

Built-in feedback loop
"Report a bug" tab → Weekly triage → Fix & analyze → Deploy to all

Bug form attaches environment + last debug log automatically. One repo, one deploy — every client benefits the same day.
