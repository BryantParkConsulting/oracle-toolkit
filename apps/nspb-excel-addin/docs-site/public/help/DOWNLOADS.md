### Install steps (Windows)

1. Download the ZIP above.
2. Right-click → **Extract All** → pick a folder you control (e.g. `C:\NSPB_MCP\installer\`).
3. Right-click `Install NSPB.bat` → **Run as administrator**.
4. Open Excel → **Insert → My Add-ins → Shared Folder** → select **NSPB MCP Assistant**.
5. The "NSPB" button appears in the **Home** ribbon.

### Install steps (Mac)

1. Download the ZIP and extract.
2. Open Finder → drop `manifest.xml` into `~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/` (create the folder if it doesn't exist).
3. Restart Excel.
4. Insert → **My Add-ins → Developer Add-ins** → select **NSPB MCP Assistant**.

> [!TIP]
> If you don't see "Developer Add-ins" on Mac, your M365 admin has disabled sideloading. See the **IT Requirements** page for centralized deployment options.
