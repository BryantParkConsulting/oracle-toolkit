# NSPB Assistant

An Excel add-in that lets your finance team **chat with NSPB** — open forms, run business rules, set substitution variables, analyze data, all from a side panel inside Excel.

Tenant-aware, persistent and multimodal, with anti-hallucination grounding in your real model.

> [!TIP]
> New here? Jump to **Use cases** for what it can do today, or **Roadmap** for what's coming.

---

## What it looks like

The add-in lives as a side panel inside Excel. Users open forms with one command and the data lands directly on a sheet, ready to refresh in SmartView.

![NSPB Assistant in Excel — form picker grouped by module](/images/excel-openform.png)

---

## What you can do

- **Open any form** with one command. Data lands in Excel ready to refresh in SmartView.
- **Run business rules** directly from chat. RTPs are auto-prompted.
- **Set / browse substitution variables** without leaving Excel.
- **Analyze a sheet** — variance, top drivers, anomalies. Real numbers, not generic advice.
- **Drill / pivot / filter** the active grid in natural language.
- **Ask anything about NSPB** — concepts, best practices, how-to. Answers reference YOUR cubes / forms / rules.

## Three steps to get going

| Step | What | Who |
|---|---|---|
| 1 — Install | Run the installer ZIP (one-time per machine) | IT |
| 2 — Set up | Import the `tenant-kb.json` the assistant emails you | End user |
| 3 — Use | Click the NSPB button in Excel and chat | End user |
